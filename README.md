# Bootstrap Web Template

A clean, responsive starter template built with Bootstrap 5.

## Quick Start

1. Open `index.html` in your browser.
2. Edit `assets/css/styles.css` to tweak theme colors and spacing.

## Features

- Navbar, hero, features, pricing, and contact sections
- Modern styling with soft shadows and CSS variables
- Mobile-first, responsive layout

## Customization

- Change theme colors in `:root` within `assets/css/styles.css`.
- Replace placeholder text and links in `index.html`.

## Dependencies

- Bootstrap 5 via CDN

---

## Restaurant Template

For a restaurant-styled site, open `restaurant.html`.

### Sections Included

- Hero cover with CTA
- About with image
- Menu grid with item cards and prices
- Reservations form
- Gallery grid
- Location with map embed
- Contact and footer

### Customize

- Replace the hero background in `.hero-restaurant` inside `assets/css/styles.css`.
- Update menu items in the `#menu` section of `restaurant.html`.
- Adjust colors via CSS variables in `:root`.
