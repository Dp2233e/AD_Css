# Bootstrap Web Template

A clean, responsive starter template built with Bootstrap 5.

## Quick Start

1. Open `index.html` in your browser.
2. Edit `assets/css/styles.css` to tweak theme colors and spacing.

## Features

- Navbar, hero, features, pricing, and contact sections
- Modern styling with soft shadows and CSS variables
- Mobile-first, responsive layout

## Customization

- Change theme colors in `:root` within `assets/css/styles.css`.
- Replace placeholder text and links in `index.html`.

## Dependencies

- Bootstrap 5 via CDN
